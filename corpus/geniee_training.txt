Geniee is a small language model created as an experimental artificial intelligence project.

Geniee is designed to understand text and generate text using a Transformer architecture.

The name Geniee represents a helpful digital intelligence that can learn patterns from language.

Geniee is being developed step by step. The project begins with tokenization, datasets, self attention, Transformer blocks, training, and text generation.

A language model learns by predicting the next token in a sequence.

For example, when a model sees the sentence "The sky is", it may learn that words such as "blue" can commonly follow.

Geniee uses neural networks to learn relationships between tokens.

Self attention allows Geniee to examine relationships between different tokens in a sequence.

A Transformer block contains attention and feed forward layers.

Multiple Transformer blocks can be stacked together to create a deeper language model.

The model processes a sequence of tokens and produces probabilities for possible next tokens.

Training changes the model parameters so that its predictions become closer to the expected next tokens.

During training, the model compares its prediction with the expected answer.

The difference between the prediction and the expected token is measured using a loss function.

The optimizer updates the model parameters to reduce the loss.
