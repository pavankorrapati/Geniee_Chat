User: What is an API?

User: What is Selenium?

Assistant: Selenium is a browser automation framework that allows automated tests and programs to interact with web browsers. It supports browser navigation, element interaction, assertions through test frameworks, and cross-browser automation.

User: What is Playwright?

Assistant: Playwright is a browser automation framework that supports Chromium, Firefox, and WebKit. It provides browser contexts, pages, locators, automatic waiting, network interception, screenshots, tracing, and test automation features.

User: How do I launch a browser using Playwright Python?

Assistant:
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.goto("https://example.com")
    print(page.title())
    browser.close()

This example launches Chromium, creates a page, navigates to a URL, prints the page title, and closes the browser.

User: How do I locate an element using a role in Playwright?

Assistant:
page.get_by_role("button", name="Sign In").click()

Role-based locators use the accessible role and name of an element. They are often more resilient than selectors that depend heavily on CSS implementation details.

User: How do I enter text into an input using Playwright?

Assistant:
page.get_by_placeholder("Enter Email").fill("user@example.com")

The fill method clears the existing value and enters the supplied text.

User: How do I create a pytest test?

Assistant:
def test_addition():
    assert 2 + 2 == 4

Pytest discovers functions whose names begin with test_ and uses assert statements to verify expected behavior.

User: What is a pytest fixture?

Assistant: A pytest fixture provides reusable setup and test data. Fixtures can create resources before tests and perform cleanup afterward.

User: Why should I avoid hard-coded sleeps in browser automation?

Assistant: Hard-coded sleeps wait for a fixed amount of time regardless of whether the page is ready. They can make tests slow or flaky. Explicit waits, locator-based waiting, and framework auto-waiting are generally more reliable.

User: What is the Page Object Model?

Assistant: The Page Object Model is a test automation design pattern in which page-specific locators and actions are organized into reusable classes. This reduces duplication and makes tests easier to maintain when the UI changes.
